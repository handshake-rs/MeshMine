# Package threat and trust notes

This is the implementation companion to MM-0001 sections 3 and 20. “Verified” below always means within the local research model.

Node-readiness references below describe fail-closed runtime loss or mismatch,
not an incomplete source matrix. MeshMine pins external node revision
`504d3fed035feb8a637ca09c4e0816b6e1144622`; all of its functional
readiness fields are true, its conditional canary permit still depends on a
coherent live tip, and its base `pre-authority` stage is replaced in live
native RPC by a mode-specific diagnostic label.

## Atomic Disconnect boundary

The verified local transaction boundary now treats a live canonical Disconnect as one indivisible mutation: the raw canonical-payment event, exact height/hash MMDB tombstone, earliest parent/session reorg markers, session closure rows, accepted-parent-head rewind, and exact canonical-sequence (`MMPC`) deletions either all commit or none do. Existing marker and tombstone bytes are exact CAS conditions and their staged sequence is `min(existing, new)`; a lost race retries the complete transition. Parent admission conditions the exact `(network, height, block_hash)` MMDB tombstone absent, so a candidate that passed its oracle check before a concurrent Disconnect cannot resurrect stale canonical state. Startup repair first validates the complete ordered raw event chain without writing, aggregates Disconnects by `(height, block_hash)` using the earliest event sequence, and performs one parent and one MaskSession evidence scan per complete CAS attempt. A malformed or gapped raw chain produces no derived reorg writes. This removes the prior per-Disconnect full-journal replay, but the aggregate scans remain history-sized under fixed safety ceilings and CAS retries can repeat them. Raw repair never fabricates missing payout-admission evidence.

All production MaskSession imports use a per-network inventory-generation handshake. Session bytes and the generation increment commit together only while the durable parent-orphan marker, exact-block MMDB tombstone, session reorg marker, and closure row are absent. Disconnect preparation and orphan-head rewind snapshot the generation before their MaskSession scan and condition their transaction on those exact bytes. Thus a session-first race invalidates the stale transition and is closed on rescan; an event-first race rejects the session without leaving journal evidence. The post-atomic trust epoch uses the normal-first proof (`MMNP`) namespace v4 (`MMN4`), active-share migration marker `MMA4`, and ordered `MMCI` migration v5 (`MMC5`); pre-atomic `MMNP` v3/`MMA3`/migration-v4 state is ignored or reset for revalidation. Rollback of the local database to pre-tombstone state remains an external monotonic-operations risk. The lifetime-bounded parent-repair/deep-reorg fence, separate active-receipt recovery composition, atomic payout-accumulator checkpoint, and every independent audit, hardware, committee, public-operator, and incident-response release gate remain open.

System-wide non-goals remain physical-majority defense, HNS-wide enforcement, on-chain slashing, guaranteed output delivery under threshold refusal, and proof of stock-ASIC nonce traversal.
