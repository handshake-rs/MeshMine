# WP1 wire vectors

`hsd-wp1.jsonl` contains deterministic golden vectors generated by `hsd` commit `698e252ebc7b5c1dd0a9587e342fdd153d020ae4`. JSON Lines is only the cross-language test transport; no MeshMine identifier or protocol hash is derived from JSON.

Each vector covers the 236-byte header, 256-byte miner representation, all padding widths, subheader, preheader, every intermediate proof hash, compact-target roundtrip, proof comparison, and Handshake's domain-separated Merkle root.

Verify the checked-in sample with:

```sh
cargo run --locked -p meshmine-hns --features vector-verifier --bin verify-hsd-vectors \
  < specs/wire-vectors/hsd-wp1.jsonl
```

The CI acceptance gate generates and checks 10,000 vectors directly against the pinned `hsd` oracle.

`core-v2.json` covers independently implemented Rust and Node.js unsigned
encodings, canonical encodings, and object IDs for all 14 Core v2 objects; the
share vector also covers its separately domain-bound work key. Both consumers
require the exact 14-name corpus, so silently omitting a newer object fails.
Verify the Node.js side with:

```sh
NODE_BACKEND=js HSD_DIR=/path/to/hsd node hsd-oracle/verify-core-vectors.js
```
